# Birthday Event Calendar

This folder is the ready-to-host version of the calendar.

## GitHub Pages

1. Create or open a GitHub repository.
2. Copy the files in this folder into the repository.
3. Commit and push them to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose `main` and the `/ (root)` folder, then save.

The app stores calendar data in each visitor's browser. No server or database is required.

Browser reminders work while the calendar is open and notification permission is enabled. Background reminders while the site is fully closed require a push-notification service.
